# Flat food icons

Source: https://github.com/microsoft/fluentui-emoji

Original assets from `assets/<Name>/Flat/`:

- `meat.svg`: Cut of meat / cut_of_meat_flat.svg
- `vegetables.svg`: Carrot / carrot_flat.svg
- `fruit.svg`: Red apple / red_apple_flat.svg
- `meal.svg`: original FreezerPal flat plate illustration with a grilled portion, broccoli, and potatoes.
- `dairy.svg`: original FreezerPal flat blue-and-white milk-carton illustration.
- `bread.svg`: Bread / bread_flat.svg
- `seafood.svg`: Fish / fish_flat.svg
- `other.svg`: Takeout box / takeout_box_flat.svg

The six Microsoft icons were downloaded November 9, 2026 and are unmodified. The prepared-meal plate and dairy carton are original app artwork. Their XML is also bundled in `src/data/foodIcons.json` for native rendering. See LICENSE.txt for Microsoft's MIT license. The same notice is included in the bundled icon data.
